## ★do-ya? から借りた「色の技法」

**役割だけ借りて、色は枕崎のものに置き換えている。**

| do-ya? | bo-rro ! | 何のため |
|---|---|---|
| `#0D0D0D`（黒） | **`--pop-dark: #071E2B`** | 完全な黒でなく**海の紺**に寄せた |
| `#FCC81E`（黄） | **`--pop-light: #EFA92B`** | 漁具の黄 |
| `#FCA5A0`（サーモン） | `--band-coral: #F5B5A8` | 朱を薄めた |
| `#A8E4F5`（水色） | `--band-sky: #A8DCE8` | 浅瀬 |
| — | `--band-moss: #BFD8C4` | 茶畑（枕崎はお茶の産地） |

### なぜ「黒 × 黄」が強いのか
```
背景 #071E2B（明度8%） × 文字 #EFA92B（明度70%）
```
- **明度差が極端**なので黄が発光して見える
- 黒は無彩色なので**黄の彩度を一切殺さない**
- **警戒色の組み合わせ**（工事現場・虎・蜂）＝本能的に目を引く

**★だから面積を絞る。** 全面に使うと疲れる。帯・バッジ・ボタンだけ。

### 使える部品

```html
<!-- 流れる黒帯（いちばん目を引く。1ページに1つまで） -->
<div class="ticker"><div class="ticker-in">
  <span>言いたいこと</span><span>◆</span>
  <span>言いたいこと</span><span>◆</span>
</div></div>

<!-- 黒い吹き出し（色帯の上に重ねるとコントラストが跳ねる） -->
<p class="bubble">どこにも載ってへんで</p>

<!-- 黒地に黄文字のバッジ -->
<span class="badge">NEW</span>

<!-- 黄の下線マーカー -->
<h2>枕崎の<span class="marker">夜は長い</span></h2>
```

### セクションの帯
```html
<section class="sec">        <!-- 白。休ませる -->
<section class="sec sun">    <!-- 黄 -->
<section class="sec coral">  <!-- サーモン -->
<section class="sec sky">    <!-- 水色 -->
<section class="sec moss">   <!-- 茶畑 -->
<section class="sec dark">   <!-- 濃紺 -->
```

**★白 → 色 → 白 → 色 と交互に挟む。** 色帯が続くと疲れる。
カテゴリページは `app.js` の `BANDS` で自動的にこの順に循環する。

### カードの黒枠
```css
border: 2px solid var(--pop-dark);
```
**影ではなく線で立体感を出す。** フラットなのに沈まない＝ポップさの正体。
色帯の上に白いカードを置いても、線があるので浮いて見える。

## ★背景イラスト

`assets/img/bg.webp`（100KB）／`bg.jpg`（150KB・フォールバック）

**枕崎の港を描いたオリジナルのイラスト。** do-ya? の「横長の絵を薄く敷いてゆっくり動かす」
という仕組みだけを踏襲し、絵は完全に自前。

### どう効いているか
- **余白が「間が持たない場所」ではなく「背景を見せる場所」になる**
- 白いセクションの裏に透けるので、色帯との**リズム**が生まれる
- ゆっくり動く（90秒で1往復）ので、止まっている感じがしない

### 調整するところ

| したいこと | 触る場所 |
|---|---|
| 濃さを変える | `.bgwrap::before` の `opacity: .30` |
| 動きを速く／遅く | `animation: bgdrift 90s` の秒数 |
| 動きを止める | `animation: none` |
| 見せる位置 | `background-position: center 28%` |
| スマホでの寄せ | `@media (max-width:720px)` の中 |

**★`opacity` は .30 以上にしないこと。** 文字が読みにくくなる。
背景の平均明度は219（かなり明るい）ので、黒文字は問題なく乗る。

### セクションの透け方

```html
<section class="sec">        <!-- 背景が透ける -->
<section class="sec paper">  <!-- 紙を敷く（読ませたい場所） -->
<section class="sec air">    <!-- ★中身なし。背景を見せるためだけの余白 -->
<section class="sec sun">    <!-- 色帯。背景を完全に隠して区切る -->
```

**カテゴリページは、中分類が4つ以上あると中盤に `air` が自動で入る。**

### 画像を差し替えるとき
`assets/img/bg.webp` と `bg.jpg` を同名で置き換えるだけ。
**横長（2.4:1 程度）で、明るく、中央が空いている絵**が向いている。

## ★背景イラスト（do-ya? の動きを実測して再現）

`assets/img/bg-tile.webp` が全ページの背景。**枕崎版のオリジナル画。**

### 設定値（do-ya? を実測 → 実機で調整して確定）

| 項目 | do-ya?実測 | **確定値** | 理由 |
|---|---|---|---|
| **横の流れ** | 21px/秒（57s相当） | **200秒** | 実機で見て「もう少し遅く」 |
| **縦の周期** | 約7.5秒 | **10秒** | 振幅を抑えたぶん、少し速いほうが揺れが分かる |
| **縦の振幅** | 約30px | **±12px** | 背景として佇ませるため控えめに |
| **濃さ** | opacity .12 | **.18** | この絵は線が細いので .12 だと消える |
| **追従** | スクロールしても動かない | **同じ** | `position: fixed` |

### ★★3層に分けている理由（重要）

```
① .bgart      画面に固定する枠（動かさない）
② .bgart-sway 縦のゆらぎ（transform の Y だけ）
③ ::before    横の流れ（transform の X だけ）
```

**理由は2つ。**

1. **`transform` は1要素に1つしか持てない。** 縦と横を同時に動かすには層を分ける必要がある。
2. **`position: fixed` に `transform` をかけると固定が壊れる。** だから枠は動かさない。

**★`margin-top` でアニメーションさせてはいけない。**
毎フレーム再レイアウトが走り、1pxずつカクついて「微細な縦ブレ」になる。
`transform: translate3d()` ならGPUで合成されるので滑らかに動く。

### 画像

| | |
|---|---|
| サイズ | 4879 × 1000px（絵2枚を横につないだもの） |
| 1枚ぶん | **2439px** ← `translateX(-2439px)` の値 |
| 容量 | webp 258KB / jpg 427KB |

**薄く敷くので画質は落としてよい**（品質58）。
ただし**解像度は落とさない**。高さが足りないと拡大されてボケる。
（当初491pxで作ったらiPhoneで1.7倍に拡大されて画質が悪化した）

### 背景の見え方をコントロールする

```css
.sec              /* 白＝背景が透けて見える（余白を楽しませる） */
.sec.sun/.coral   /* 色帯＝不透明。背景が消えて区切りが立つ */
.sec.dark/.mid    /* 濃紺＝同上 */
```

**do-ya? は「余白が多くても気にならない」どころか、余白で背景を見せている。**
だから白セクションは透明にして、色帯で締める。

### 差し替えたいとき
`assets/img/bg-tile.webp` を置き換えるだけ。
**横に同じ絵を2枚つないだ画像**にすること（継ぎ目を出さないため）。
`bgflow` の `translateX(-1200px)` を、絵1枚ぶんの幅に合わせて直す。

### 速度を変えたいとき
```css
animation: bgflow 57s linear infinite,     /* 数字を大きく＝ゆっくり */
           bgsway 7.5s ease-in-out infinite alternate;
```

**※ホーム（index.html）は海のグラデーションが背景なので、イラストは出していません**
（`<body class="dark no-bgart">`）。

## よくやること

### 店を追加する
`assets/data.js` の `SHOPS` に1行足すだけ。**HTMLは触りません。**
中分類（`sub`）が新しければ、セクションも自動で増えます。

```js
{ slug:"新しい店のslug", name:"店名", kana:"よみ",
  cats:["eat"], primary:"eat", sub:"cafe", subLabel:"カフェ",
  address:"○○町1-2", tel:"0993-00-0000",
  hours:"10:00-18:00", closed:["mon"],
  lead:"一行紹介。自分の言葉で書く。" },
```

`slug` は**小文字の英数字とハイフンのみ**。一度公開したら変えないこと。

### そのページの「顔」を変える
各HTMLの `buildCategory()` の引数。

```js
buildCategory("eat", {
  headline: "見出し",
  lead: "説明文",
});
```

`drink.html` のように、ヒーローを直接HTMLで書くこともできます
（`<div id="hero" data-custom="1">` にすると自動生成をやめます）。

### セクションの日本語ひとことを変える
`assets/app.js` の `LABEL_JA` / `LABEL_EN`。

### 色を変える
`assets/style.css` の一番上、`:root` の中だけ。

### カテゴリを公開する
`assets/data.js` の `CATEGORIES` で `ready:false` → `true`。
そのHTMLの `buildSoon("id")` を `buildCategory("id", {...})` に変える。

## 設計の約束

1. **店舗の実体は `shop.html?s=slug` に1つだけ。** カテゴリごとに複製しない
2. **slug は不変。** 変える場合はリダイレクトを残す
3. **ページは手で作らない。** `data.js` に足せば一覧にも詳細にも出る
4. **閉店した店は消さない。** 記録を残す
5. **`data-track` 属性で計測する。** 電話・地図・Instagram のタップを1箇所で拾う
6. **絶対パスを使わない。** すべて相対パス（`eat.html`）。だからどこに置いても動く

## デザインの考え方

出発点は**枕崎漁港に浮かぶ「浮き（ブイ）」**。

- 背景は夜明け前の海。白は泡
- カテゴリの6色は、実際の漁具の配色から採った
- 見出しは丸ゴシック（Zen Maru Gothic）
- 数字は等幅（Roboto Mono）。営業時間・電話番号・料金が縦に揃う

### 文字の太さ
**本文の基準は 400 ではなく 500。**
日本語は 400 だと画面上でスカスカに見える。
**補足も 400 に落とさない。** 弱さは太さではなく色で作る。

### 動きへの配慮
- `prefers-reduced-motion` を尊重し、物理演算を起動しない
- タップ領域は最小 56px（高齢化率43.8%の街なので）
- 横スライドは指でも動くが、スクロールバーは隠している
